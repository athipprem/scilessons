What Gets Copied? (Route A)

A nucleus holds long thin threads called chromosomes. This cell has 4. Press the buttons and watch.
parent cell: 4 chromosomes → each new cell: 4 chromosomes
The nucleus holds 4 chromosomes. Every chromosome has made an exact copy. The two copies stay joined in the middle, so each looks like an X. The copies pulled apart, one to each side, and the cell split in two. Each new cell has all 4 chromosomes.

Same Story, as Steps (Route B)

Same story, as steps you can write.
  1. The nucleus holds the chromosomes.
  2. Before splitting, every chromosome is copied.
  3. The two copies stay joined: an X.
  4. When the cell splits, the copies pull apart, one to each new cell.
  5. So each new cell gets the same chromosomes as the parent. That is why the two new cells are identical.
Unit 44 told you the new cells are identical. Now you know why.

Why the Copy Must Be Perfect

Imagine copying a recipe by hand. Miss one line and the cake fails. A cell works from instructions too. These instructions are called genes, and they sit along the chromosomes.
If a copy has a piece missing, the new cell that gets it lacks something it needs. That is why a cell copies every chromosome carefully before it splits.

The Cell Cycle Is a Loop

Press the button to run one cell cycle.
Press the button to run one cycle. Growing and doing its job. This is the long part. Dividing! This is the short slice. Two new cells, each half-sized. Each one starts its own loop, growing first.
Cells do not divide all the time. Most of a cell's time is spent growing and doing its job. A new cell grows to full size before it can divide again.

Where Is Division Fastest?

In a plant, cells divide fastest at the root tip and the shoot tip, where the plant grows longer (Unit 33). In an animal, division is fastest where cells are replaced all the time, like the bottom layer of skin and the lining of the gut.
