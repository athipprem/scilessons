📊 Priority Refresher 1 — Fair Tests & Reading Graphs

Fair-test vocabulary: the INDEPENDENT variable is the ONE thing you deliberately CHANGE on purpose. The DEPENDENT variable is the thing you MEASURE as your result. Every CONTROLLED variable is something you deliberately keep THE SAME, so it can't unfairly affect the result.
Reading an experiment description — which role does each variable play?
The ONE thing changed on purpose
Independent variable
The thing measured as the result
Dependent variable
Everything else, kept identical
Controlled variable(s)

Worked example — reading a graph carefully: the bar chart below shows a class's beetroot seedlings, measured in centimetres every week for four weeks.

Growth between weeks: Wk1→2 = +3cm, Wk2→3 = +2cm, Wk3→4 = +1cm. Even though the bars keep getting taller, the AMOUNT of new growth each week is actually slowing down — always calculate the difference between bars, don't just compare their heights by eye.

Quick Check 1: Using the SAME chart above, between which two weeks did the seedlings grow the MOST extra height?

✔ Correct — Week 1 to Week 2 added 3cm (3→6), more than any other single week's growth (2cm, then 1cm).
✘ Calculate each week's DIFFERENCE from the one before: Wk1→2 = +3cm, Wk2→3 = +2cm, Wk3→4 = +1cm. The biggest jump is Week 1 to Week 2.

Quick Check 2: A student tests three different fertilisers on identical seedlings, using the SAME pot size, SAME soil, and SAME amount of water and sunlight for all three. What is the INDEPENDENT variable — the one thing being deliberately changed?

✔ Correct — fertiliser type is the ONE thing deliberately changed between the three groups; everything else is kept the same on purpose.
✘ Water, pot size, and final height are all either kept the SAME (controlled) or the RESULT being measured (dependent) — only fertiliser type is deliberately varied.

🧲 Priority Refresher 2 — Magnet or Magnetic Material? Read Carefully

The rule: being PULLED toward a magnet only proves an object is made of a MAGNETIC MATERIAL — never that it IS a magnet. The test is always the same: can it pull OTHER magnetic objects toward itself, all on its own, with no outside magnet helping?

On Unit 34's test, one question asked "what does this tell us?" after describing an object that got pulled by a magnet but then couldn't pull anything itself. The trap was an answer that seemed to fit the FIRST half of the story ("it got pulled...") while actually contradicting it. Before choosing an answer on a question like this, re-read the whole set-up ONE more time — check your answer doesn't quietly disagree with something you were already told.

Quick Check 3: A steel washer is pulled toward a strong magnet lying on a desk. Later, with the magnet locked away in a drawer, the same washer is held next to a small heap of loose iron filings — none of the filings move at all. What does this tell us about the washer?

✔ Correct — the washer got PULLED by a real magnet (proving it's a magnetic material), but it couldn't pull the filings on its own (proving it is NOT itself a magnet).
✘ Careful — the washer WAS pulled by the magnet earlier in the story, so "steel isn't magnetic" directly contradicts that. Being pulled proves magnetic material; failing to pull other objects on its own proves it's not a magnet itself.

🔗 Priority Refresher 3 — Longer Magnet Chains, One Join at a Time

The method (works for ANY chain length): every single magnet has a North end AND a South end — never just one. Check ONE join at a time. SAME poles touching → REPEL. DIFFERENT poles touching → ATTRACT. Write down each magnet's poles as you go — never try to hold the whole chain in your head at once.
This time the GIVEN pole is at the far end of the LAST magnet (F's far-right end = S), not the first — the method is identical, you just work backwards through the chain instead of forwards.
Step 1: F's far-right end is S (given). F's left end (touching E) must be N, since every magnet's two ends are opposite.
Step 2: The E–F join ATTRACTS, meaning the two touching ends are DIFFERENT. F's left is N, so E's right end (touching F) must be S.
Step 3: E's left end (touching D) must be N, since E's two ends are opposite.
Step 4: The D–E join REPELS, meaning the two touching ends are the SAME. E's left is N, so D's right end (touching E) must ALSO be N.
Step 5: D's far-left end (not touching anything) must be S, since D's two ends are opposite.

Quick Check 4: Using the SAME chain above, what is Magnet D's far-LEFT end (the one not touching anything)?

✔ Correct — working backwards from F's given S end, through both joins one at a time, D's right end lands on N, so D's far-left end (opposite) is South.
✘ Look at Steps 1-5 again — work through EACH join in order, one at a time: F's left = N, E's right = S (attract), E's left = N (opposite ends), D's right = N (repel = same), D's far-left = S (opposite ends).
